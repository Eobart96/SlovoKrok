## 2026-10-05 — Устранён ложный HTTP 500 при сохранении заданий

- По launcher-логам причина определена как proxy `ECONNRESET` во время WatchFiles reload: backend не фиксировал HTTP 500, а сохранённая попытка уже оставалась в SQLite.
- Для создания, проверки и удаления упражнений, чтения и домашней работы добавлено read-only восстановление результата без повторного изменяющего запроса.
- Ошибки provider сохраняют контракты 502/503/504; ошибки записи SQLite откатываются и возвращают стабильную 503.
- Backend launcher теперь следит только за `backend/app`; после перезапуска backend health `ok`, frontend отвечает 200.
- Проверено: 105 backend и 32 frontend unit-теста, A1/TypeScript, production build, bundle budget, repository audit и `git diff --check`; UI/Playwright не запускались по правилу проекта.
