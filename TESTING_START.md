# SlovoKrok — знакомство для тестировщика

Это локальный курс словацкого A1: 8 модулей, 83 урока, объяснения на русском,
практика, словарь, чтение, домашние задания и работа над ошибками. Это версия
для обратной связи, а не завершённый коммерческий продукт. Modules 7–8 ещё
ожидают полной ручной приёмки. Интерактивный A2 пока не доступен.

## Первый запуск на Windows

1. Распакуйте ZIP целиком в отдельную папку. Не запускайте файлы внутри ZIP.
2. Установите Python 3.12+ и Node.js 22+, если их ещё нет на компьютере.
   При установке Python включите добавление в PATH.
3. Откройте `install.cmd` в распакованной папке. Он скачает зависимости;
   для установки нужен интернет.
4. После завершения установки откройте `start.cmd`.
5. Дождитесь браузера с `http://127.0.0.1:3000/`. Появится знакомство с курсом.
6. В `Настройки → Задания` нажмите **«Добавить базовый пакет»**. Он добавит
   для всех 83 тем по 20 упражнений, 2 текста и 2 ДЗ без обращения к ИИ.
   Материалы соответствующей темы станут доступны после её завершения.

Если курс не открылся, запустите `doctor.cmd` и передайте автору текст ошибки.
Для остановки приложения используйте `stop.cmd`.

Архив содержит исходники и инструкции, не готовый установщик. В нём нет
зависимостей, личного прогресса, профиля и ключей автора. Учебные PDF A2 в этот
архив не включены; они распространяются отдельно.

## Где что находится

Верхнее меню: **Обучение → Шпаргалки → Упражнения → Домашнее задание →
Чтение → Ошибки → Слова**.

- **Обучение:** выберите первую тему, прочитайте материал и выполните практику.
- **Шпаргалки:** краткие правила и ваши заметки.
- **Упражнения:** практика по завершённым темам, разделам или модулям.
- **Домашнее задание:** свободные ответы и объяснение проверки.
- **Чтение:** текст и пересказ смысла. Диктовка зависит от браузера и интернета.
- **Ошибки:** повторение трудных мест; добавляйте их кнопкой «Записать ошибку».
- **Слова:** словарь пройденных тем.

**Настройки:** «О себе», оформление, режим онлайн/офлайн, подключение ИИ,
перенос заданий и резервная копия. **Как пользоваться** повторно открывает
приветственное окно. Переводчик находится рядом с настройками.

## Нужно ли подключать ИИ

Встроенные уроки, их практика и общий базовый пакет доступны без подключения.
Пакет находится в `Настройки → Задания` и уже включён в исходники/архив.
Для генерации новых
упражнений, чтений, ДЗ и смысловой проверки нужен ваш собственный Codex CLI,
OpenAI или Polza. Выберите provider в настройках; чужие ключи не используйте.
API может быть платным. При работе ИИ текст запроса передаётся этому provider.

В онлайн-режиме задания с точным эталоном проверяются сразу без ИИ. В офлайн-
режиме доступны сохранённые задания с эталоном; открытые ответы оцениваются
приблизительно по ключевым словам. Старые задания без эталона требуют ИИ.

«О себе» необязателен. Разрешение передавать профиль ИИ изначально выключено.
Для замены имени/деятельности в примерах заполните русскую и словацкую формы.
Фиксированные тесты и старые задания сохраняют исходные условия.

## Что попробовать

1. Пройти одну тему: теория, практика, переходы между шагами.
2. Перейти в другой раздел и вернуться; проверить продолжение работы.
3. После завершения темы создать упражнение или чтение (если ИИ подключён).
4. Записать ошибку и пройти её повторение.
5. Проверить светлую/тёмную тему и размер текста на своём устройстве.

Сообщайте также о непонятном объяснении, неверном переводе и неудобной кнопке.

## Как передать проблему автору

1. Откройте значок сообщения внизу слева на экране с проблемой.
2. Напишите, что делали, что ожидали и что произошло; укажите браузер.
3. Нажмите «Снимок экрана» и выберите окно SlovoKrok. Проверьте снимок:
   на нём не должно быть информации, которой вы не хотите делиться.
4. Сохраните обращение.
5. Нажмите «Скачать ZIP» и передайте архив человеку, который пригласил вас
   тестировать приложение. Само приложение обращения не отправляет.

Очистка списка обращений удаляет их локально вместе со скриншотами;
сначала скачайте архив, если хотите их сохранить.

## Где сохраняется работа

Данные на Windows находятся в `%LOCALAPPDATA%\SlovoKrok`, а прогресс также
кешируется браузером. Общего аккаунта и облачной синхронизации нет.
Новая папка с исходниками на том же компьютере использует существующие данные:
это обновление приложения, а не сброс. Для курса используйте резервную копию
в настройках; профиль «О себе» и обращения в неё не входят.

Не открывайте приложение в сеть: версия рассчитана на работу на вашем
компьютере через `127.0.0.1`. Не передавайте ключи ИИ, полный backup или папку
данных для обычного сообщения об ошибке.
