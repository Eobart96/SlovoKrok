# Логотип SlovoKrok

- `../../frontend/public/branding/slovokrok-logo.png` — оригинальный PNG с прозрачным фоном, выбранный владельцем; используется в шапке A1/A2.
- `slovokrok-logo.svg` — редактируемая векторная перерисовка: облако, ступеньки, герб и текст разделены. Это отдельная реконструкция, не точная векторизация PNG. Текст редактируется; его вид зависит от установленного шрифта.

В шапке PNG показывается без белой подложки. Тёмная тема повышает яркость через CSS-фильтр; исходные файлы не изменяются. Логотип и служебные кнопки находятся сверху, разделы курса — отдельным рядом; на узких экранах разделы складываются в две колонки.

PNG создан встроенным ImageGen. Концепция и финальное задание: горизонтальный SlovoKrok, синие Slovo и красные Krok, речевое облако со ступеньками белого, синего и красного цветов; в свободном верхнем левом углу облака красный щит, белый двойной крест и три синих холма. Прозрачный фон.

Цвета SVG: синий `#0B4EA2`, красный `#EE1C25`, белый `#FFFFFF`. SVG можно открыть в Inkscape, Figma или Illustrator. Для внешнего использования без изменения композиции берите оригинальный PNG.
