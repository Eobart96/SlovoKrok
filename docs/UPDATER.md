# Обновление Windows

В установленной из ZIP версии запустите `update.bat`. Интернет необходим.
Обновление проверяет последний стабильный выпуск GitHub Eobart96/SlovoKrok.
Если выпусков ещё нет, приложение остаётся без изменений.

Новая версия устанавливается в соседнюю папку. После успешного запуска
используйте `start.cmd` и `update.bat` из указанной новой папки; старую папку
и снимок данных сохраняйте до проверки прогресса. Существующие ярлыки
автоматически не меняются. Git-папки не обновляются этим способом.

Перед запуском новой версии прежний launcher останавливается; занятые порты
блокируют обновление. Данные копируются целиком после остановки, включая
SQLite sidecars. Настройки `.env` переносятся локально без вывода содержимого.
Зависимости устанавливаются заново в конечной папке новой версии.

Если запуск не удался, updater останавливает новую версию и сообщает пути
старой установки и снимка данных. Автоматического восстановления данных нет:
новая версия могла уже выполнить миграцию. Для возврата нужны старая версия
и её снимок данных, восстановленный при остановленном приложении.

## Подготовка выпуска владельцем

1. Подготовить проверенный пакет через `scripts/package-testers.py`.
2. Опубликовать стабильный GitHub Release с тегом `vMAJOR.MINOR.PATCH`.
3. Прикрепить пакет как `SlovoKrok-windows.zip`, с корневой папкой `SlovoKrok/`.
   Пакет должен включать `update.bat` и оба Windows PowerShell-скрипта.
4. API GitHub должен возвращать для asset `digest` вида `sha256:…`:
   updater сравнивает его со скачанным архивом перед распаковкой.

Прямое обновление из main и автоматическая публикация выпусков не предусмотрены.
`powershell.exe -File scripts/windows/update.ps1 -CheckOnly` проверяет наличие
выпуска без скачивания, остановки или установки. Защита Git-папки действует
и в этом режиме. Реальное обновление и установка на чистой Windows требуют
проверки на отдельной копии с подготовленным выпуском.
