# Новости GitHub и сайта

При каждом опубликованном обновлении приложения вместе с кодом обновляются:

- `CHANGELOG.md`: подробности для разработчиков, исправления и проверки.
- `UPDATES.md`: описание для владельца и пользователей GitHub.
- `updates/public.json`: короткие новости для сайта без технических подробностей.

На сайте писать результаты для ученика: «Исправлены мелкие ошибки»,
«Улучшено сохранение прогресса», «Добавлены новые задания».
Не перечислять внутренние имена, библиотеки, тесты и устройство программы.
Не объявлять исправленным то, что ещё не проверено.

Новые записи в `updates/public.json` добавлять сверху. Сохранять старые `id`,
формат `schemaVersion: 1`, дату `YYYY-MM-DD`, заголовок и список `changes`.
У новой версии указывать `version` (например, `0.2.0`); номер должен совпадать
с `frontend/package.json` и корневыми записями `frontend/package-lock.json`.
Перед публикацией выполнить `node scripts/check-public-updates.mjs`.
Эта же проверка включена в GitHub CI.

Сайт https://slovokrok.eobart2.chatgpt.site при открытии главной страницы
или отдельной страницы `/updates.html` (вся история с датами)
загружает новости из `updates/public.json` ветки `main` репозитория
`Eobart96/SlovoKrok`. После публикации этого файла в GitHub раздел «Что нового»
обновляется при следующем открытии или перезагрузке страницы. Возможна задержка
кэша GitHub. При недоступности GitHub остаётся краткая сохранённая новость
о версии для тестирования; ошибка загрузки не мешает пользоваться сайтом.
На странице обновлений номер версии выводится рядом с датой; сохранённая
копия новостей сайта обновляется при его публикации, чтобы при сбое были видны
последние опубликованные изменения.

Локальная запись ещё не означает выпуск. Пока код не опубликован, его изменения
остаются в разделе «Не опубликовано» и не объявляются доступными на живом сайте.
Commit/push/release требуют явного разрешения владельца.

Этот механизм обновляет новости. Для изменения описания курса, снимков,
ссылок или оформления нужно отдельно обновить и опубликовать исходники сайта
в `website/slovokrok`. Сайт и исходники приложения хранятся отдельно.
