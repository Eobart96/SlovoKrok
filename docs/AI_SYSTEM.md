# AI tutor

Профиль «О себе» хранится отдельно и передаётся выбранному provider только при
`share_with_ai=true`. Обёртка provider добавляет JSON как данные, а не инструкции;
новые задания учитывают имя, деятельность и интересы в границах изученной темы.
Проверка существующих заданий и перевод не должны подменять исходные факты.
Без разрешения примеры уроков адаптируются локально, а provider профиль не получает.

ДЗ чередуют шесть предпочтительных действий по числу сохранённых заданий текущей
учебной области. При согласии на персонализацию генератор видит последние восемь
условий этой области (без ответов/оценок) и должен менять цель и действие,
а не только имя или формулировку. Интересы и цель профиля задают ситуацию;
изученная грамматика и обязательная структура задания остаются границами.
Без согласия история условий не передаётся, поскольку в ней могут остаться
личные сведения. Чередование и локальная проверка одинаковых условий сохраняются.
Дубли условий без учёта регистра/пробелов отклоняются с 502 до записи.
Смысловая непохожесть пока задаётся инструкцией ИИ, а не гарантируется алгоритмом.

Provider выбирается на экране «Настройки ИИ» либо исходным
`TUTOR_PROVIDER=codex|openai|polza`. По умолчанию backend вызывает локальный
Codex CLI. Для OpenAI и Polza интерфейс принимает API-ключ и передаёт его
только backend. Настройки сохраняются вне репозитория в
`%LOCALAPPDATA%\SlovoKrok\ai_settings.json` (или абсолютном
`SLOVOKROK_DATA_DIR`); `.env` остаётся поддерживаемым источником начальных
значений. Legacy-файл из `backend/data/` при необходимости копируется без
удаления оригинала.

API возвращает только `*_api_key_configured: true|false`, поэтому сохранённый
секрет не попадает обратно в браузер. Выбор API-provider без ключа отклоняется
с `422`. Локальное хранилище не зашифровано и рассчитано на однопользовательский
компьютер; файл нельзя добавлять в Git или пересылать.

Polza вызывается через поддерживаемый сервисом OpenAI-compatible endpoint
`/chat/completions`, а прямой OpenAI — через Responses API. Рекомендуемая
экономичная модель для переводов, объяснений и генерации учебных заданий —
`google/gemini-2.5-flash-lite`; имя модели остаётся настраиваемым. Для Polza
ответ ограничен 4096 токенами и низкой вариативностью, чтобы сдерживать стоимость
и стабильнее получать требуемый JSON.

Tutor получает ограниченный контекст урока, текущую задачу, тип реплики и до
шести последних сообщений. Тексты для чтения строятся вокруг одной ситуации
со связанными фразами и постоянными участниками. При малом изученном словаре
можно сократить текст до 30–70 слов вместо 80–120; квота на восемь слов убрана.
Русский эталон составляется по окончательному тексту без добавленных событий.
Чтения A1/A2 показываются отдельно. A2: обычно 100–150 слов (70–100 при узком
материале), 3–5 связанных фактов, причина/затруднение и результат по изученной
грамматике. Онлайн-проверка берёт уровень из сохранённого slug текста: для A2
неясная ключевая причина/решение/итог ограничивает оценку 89 по инструкции ИИ;
оговорки диктовки допустимы, отсутствующие факты не достраиваются за ученика.
Это инструкция модели, не программная гарантия оценки. Офлайн-проверка остаётся
приблизительным сравнением ключевых слов; отдельный список A2 ожидается от владельца.
Упражнения с сохранёнными парами или допустимыми
ответами проверяются по эталону без вызова AI и в online, и в offline режиме.
В online режиме AI проверяет только старые упражнения без эталона.
В заданиях `order` слова сохраняют перемешанный порядок, но регистр и конечные
знаки препинания восстанавливаются по первому сохранённому эталону при совпадении
набора слов. Это работает и для старых заданий при чтении, без записи в SQLite.
Ответы внешней модели считаются недоверенными:
backend ограничивает сырой ответ 32 000 символами, извлекает JSON и валидирует
его строгим Pydantic-контрактом без лишних полей и неявного преобразования
типов. Строки, массивы и `score` имеют явные границы. API возвращает `502` при
неверном формате, `503` при недоступном provider и `504` при timeout, не
включая внутренний текст исключения provider в ответ браузеру.

Codex CLI и OpenAI-compatible запросы ограничены `TUTOR_TIMEOUT_SECONDS`.
Timeout завершает ожидающий вызов; OpenAI SDK выполняет не более одного
встроенного retry только для поддерживаемых им временных ошибок. Ответ Codex
дополнительно ограничен 128 000 байт до чтения файла.

При проверке домашнего задания Codex CLI получает `--output-schema` со схемой
`TutorAssessment`: формат задаётся при генерации, затем независимо проверяется
Pydantic. Исправленный ответ всегда непустой, включая правильные ответы ученика;
оценка определяется по ответу, а не копируется из JSON-примера.

Отдельно браузерный request layer ждёт AI-операцию не более 310 секунд — дольше
максимального backend timeout в 300 секунд. Поэтому обычный timeout provider
возвращается как контролируемый `504`, а не маскируется ранней отменой fetch.
Frontend transport не повторяет один HTTP-запрос автоматически; встроенный
retry provider выше остаётся внутренней частью одного backend-вызова.

Codex CLI запускается из отдельной пустой временной рабочей директории вне
репозитория. Это не даёт prompt-контексту автоматически видеть файлы проекта;
директория обычного запроса и проверки статуса удаляется сразу после процесса,
а директория интерактивного входа — после закрытия процесса входа.

Плавающий переводчик использует тот же выбранный provider, но отдельный
ограниченный prompt без профиля ученика и материалов курса. Он переводит текст
до 2 000 символов только между русским и словацким, не исполняет инструкции из
исходного текста и принимает лишь валидированный структурированный ответ.
После готового перевода пользователь может задать один контекстный вопрос.
Отдельный ограниченный prompt получает только исходный текст, перевод,
направление и вопрос; все эти значения считаются недоверенными данными, а ответ
также проходит Pydantic-валидацию.

Методика, roadmap и публичный пример профиля находятся в
`course-content/slovak-a1/learning/`. Локальный профиль
`.ai/private/student_profile.local.md` не входит в Git и по умолчанию не
передаётся ни одному provider. Для осознанного opt-in владелец может установить
локальную переменную `SHARE_PRIVATE_TUTOR_PROFILE=true`; тогда локальный профиль
заменит публичный пример в tutor prompt. Переводчик профиль не получает при
любом значении настройки.
