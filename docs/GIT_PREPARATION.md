# Состав публичного репозитория

SlovoKrok содержит исходники приложения, зависимости в lock-файлах,
CI, документацию, общий пакет заданий A1 и учебные PDF A2.

## Структура

| Папка | Назначение |
|---|---|
| `frontend/` | Интерфейс, уроки, публичный пакет заданий и frontend-проверки |
| `backend/` | API, хранение состояния и backend-проверки |
| `course-content/` | Учебные планы и исходные тексты общего пакета |
| `docs/` | Документация и скриншоты приложения |
| `output/pdf/A2/` | Учебные PDF, сгруппированные по модулям |
| `output/txt/` | Общие промты для учебных материалов |
| `scripts/` | Инструменты запуска, сборки и проверки |
| `.github/` | Автоматические проверки и шаблоны обращений |

В корне находятся README на трёх языках, установка/запуск, лицензия,
инструкция тестировщикам и правила участия в проекте.

## Только локально

`.gitignore` исключает личные инструкции `.ai/`, `.codex/`, `.agents/`,
`AGENTS.md`, рабочие checkpoint/history/report, env-секреты, SQLite,
резервные копии, зависимости, сборки, кэш и временные архивы.
Инструменты, требующие личных навыков агента или локального checkpoint,
тоже остаются локальными. Исключение из Git не удаляет эти файлы с компьютера.

## Проверка состава

Из корня проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/windows/check-repository.ps1
node scripts/git-candidate.mjs --write tmp/git-candidates/review.json
node scripts/git-candidate.mjs --verify tmp/git-candidates/review.json
git diff --check
```

Для нового manifest используйте новое имя. Проверка manifest сравнивает
пути, размеры и SHA-256; файлы не должны изменяться между записью и проверкой.
Команды не выполняют commit или push.

Отдельную копию исходников при необходимости создаёт `scripts/package-github.py`;
она не включает `.git` и личные данные. Копия без `.git` не меняет историю
существующего репозитория. Локальная проверка состава не подтверждает
чистую установку, работу ИИ или ручную приёмку интерфейса.
