# Общий базовый пакет SlovoKrok A1

83 темы текущего курса. На каждую тему: 20 упражнений, 2 текста и 2 домашних
задания. Всего 1660 / 166 / 166, то есть 1992 задания. Пакет нейтральный:
без имён, профиля владельца, личных ответов, оценок и истории ошибок.

Готовый файл: `frontend/public/task-packs/slovokrok-a1-basic-v1.json`.
Формат существующего tasks-only переноса: `slovokrok-course-materials`, version 1.
Все упражнения содержат эталон; тексты и ДЗ — образец смыслового ответа.
Закрытые упражнения проверяются без ИИ. Открытые offline-ответы проверяются
приблизительно, online — по смыслу через выбранный provider.

## В приложении

`Настройки → Задания → Добавить базовый пакет`. Скачивать/загружать файл вручную
не требуется. Повторный импорт пропускает совпадающие записи. Существующие
задания, прогресс и попытки не удаляются. Материалы доступны по обычным правилам
после завершения соответствующей темы; импорт сам по себе не завершает уроки.

## Состав и воспроизведение

- Упражнения: материал практик текущего курса, отдельные вопросы из составных
  заданий, с исходными правильными ответами. Выбраны 20 разных заданий на тему.
- `texts-1-4.json` / `texts-5-8.json`: отдельные связные учебные тексты и ДЗ;
  это редактируемый источник для повторной сборки.
- `scripts/build-basic-task-pack.cjs` воспроизводит общий JSON без AI, с
  постоянной датой пакета и неизменными slug тем. Нужен установленный frontend.
- `scripts/validate-basic-task-pack.py` проверяет количество, структуру,
  уникальность, совместимость эталонов и изолированный импорт.

```powershell
node scripts/build-basic-task-pack.cjs
backend/.venv/Scripts/python.exe scripts/validate-basic-task-pack.py
```

Не экспортируйте личную базу вместо этого файла. Обновление текста/условий
задания меняет его ключ дедупликации и при повторном импорте создаёт новую
запись; уже установленный старый пакет автоматически не переписывается.
