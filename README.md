## Быстрый запуск на Windows

Нужны Python 3.12+ и Node.js 22+. После скачивания исходников:

При установке Python включите добавление в PATH. Для загрузки зависимостей
нужен интернет. Можно скачать ZIP GitHub или использовать Git:

```powershell
git clone https://github.com/Eobart96/SlovoKrok.git
cd SlovoKrok
```

1. Откройте `install.cmd` — для загрузки зависимостей нужен интернет.
2. Откройте `start.cmd` — приложение откроется на http://127.0.0.1:3000/.
3. В настройках заданий нажмите **Добавить базовый пакет**.

`doctor.cmd` проверяет окружение, `stop.cmd` останавливает приложение.
Подробнее: [инструкция для тестировщика](TESTING_START.md).

## Базовые задания

Для каждой темы A1: **20 упражнений, 2 текста и 2 домашних задания**.
Всего **1660 упражнений, 166 текстов и 166 ДЗ** без имён и личного профиля.
Материалы доступны после завершения соответствующей темы. Повторное добавление
пропускает совпадающие записи и сохраняет прогресс.

[Готовый JSON](frontend/public/task-packs/slovokrok-a1-basic-v1.json) ·
[Состав и пересборка](course-content/basic-task-pack/README.md).

Уроки и базовый пакет доступны без подключения ИИ. Задания с точным эталоном
проверяются локально. Офлайн-проверка открытых ответов приблизительная;
для смысловой проверки и генерации новых заданий нужен собственный Codex CLI
или OpenAI-совместимый provider. API может быть платным.

## Что добавлено в приложении

- Приветственное окно и повторный просмотр инструкции.
- Возврат к последнему заданию в упражнениях, чтении и ДЗ; сохранение позиции разделов.
- Локальная проверка заданий с эталоном даже в онлайн-режиме.
- Запись ошибки из задания, разбор, повторная практика и закрепление.
- Голосовой пересказ в чтении; онлайн-проверка учитывает смысл, оговорки
  и словацкие слова внутри русской диктовки. Распознавание зависит от браузера и интернета.
- Необязательный профиль для адаптации примеров; настройки темы и размера текста.
- Обращения с местом возникновения ошибки, снимком экрана, ZIP-экспортом и очисткой списка.
- Перенос заданий через JSON, базовый пакет, резервные копии и управление заданиями.

## Интерфейс

Обучение → Шпаргалки → Упражнения → Домашнее задание → Чтение → Ошибки → Слова.
Настройки содержат оформление, необязательный профиль, подключение ИИ,
перенос заданий и резервные копии. При первом входе открывается знакомство.
Обращения со скриншотами можно скачать и передать автору отдельным архивом.

## Структура

- `frontend/` — Next.js, React, TypeScript, уроки и базовый пакет.
- `backend/` — FastAPI, SQLAlchemy, SQLite, проверка и генерация заданий.
- `course-content/` — методика и редактируемые источники пакета.
- `output/pdf/A2/` — 72 учебных PDF A2; в приложении доступны 31 тема: полные модули 1–3 и темы 4.1–4.3 модуля 4: переход к A2, вид, порядок слов, связная речь, падежи, описание и количество. Названия модулей английские, объяснения русские. Уровень A1/A2 выбирается в настройках; шапка оформлена одинаково для обоих уровней. Ручная проверка новых тем будет позже пакетом.
- `scripts/` — запуск, сборка материалов и проверки.
- `.github/` — CI и шаблоны обратной связи.
- `docs/` — техническая документация.

## Данные и ограничения

Это локальное однопользовательское приложение. На Windows пользовательские
данные находятся в `%LOCALAPPDATA%\SlovoKrok`; исходники не содержат базы,
API-ключей, личного профиля и прогресса автора. `.env` необязателен,
пример настроек — `.env.example`. Профиль передаётся ИИ только с разрешения.
Новая папка приложения на том же компьютере использует существующие данные.

Владелец проверил и принял все 8 модулей A1: 83 из 83 тем.
Версия предназначена для тестирования. Установка на чистом компьютере
и общая приёмка текущих функций интерфейса остаются отдельным этапом.
Публичный сервер, регистрация и многопользовательский режим не подготовлены.

## Обновление

1. Сохраните резервную копию в настройках и остановите приложение через `stop.cmd`.
2. Если проект скачан через Git, выполните `git pull --ff-only` в папке проекта.
   При собственных изменениях сначала сохраните их; не используйте принудительный сброс.
   Для ZIP скачайте свежие исходники и распакуйте в новую папку.
3. Снова запустите `install.cmd`, затем `start.cmd`.
4. Добавьте базовый пакет, если он ещё не установлен; одинаковые задания будут пропущены.

Профиль и прогресс не входят в исходники. На том же компьютере сохраняется
прежняя папка данных. Для переноса на другой компьютер используйте резервную
копию; отдельный экспорт заданий не переносит ответы и оценки.
