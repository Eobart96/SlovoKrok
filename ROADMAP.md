## Открытые технические вопросы

- Подтвердить отзыв прежнего provider-ключа, след которого ранее обнаружен
  в Git-истории; значение ключа не записывать.
- Проверить текущий CI и Python dependency audit. Старые проверки не заменяют
  проверки новой версии; устаревший пункт о 6 npm high advisories снят.
- Реальный платный запрос Polza остаётся непроверенным; выполнять только
  по отдельному разрешению владельца.
- Офлайн-проверка открытых ответов приблизительная; смысловая оценка требует ИИ.

## Возможные улучшения после текущего этапа

Эти задачи остаются в резерве и не запускаются автоматически:

- URL-навигация к модулю и уроку; общий контракт курса и версия учебного содержания.
- Миграции SQLite через Alembic перед будущим физическим изменением схемы.
- Универсальный tutor-контракт с совместимостью старого API и проверкой типов API-клиента.
- Отдельные учебные события, рекомендации по освоению темы и более точное интервальное повторение.
- Расширяемые типы заданий, аудирование и произношение после решения хранения аудио.
- Инструменты подготовки материалов следующих уровней.

Регистрация, несколько пользователей, PostgreSQL, облачный сервер,
синхронизация между устройствами и облачное хранение аудио требуют
отдельного запроса. Текущий продукт остаётся локальным приложением.
