# Project checkpoint

Обновлено: 2026-09-23

Этот файл — короткая точка продолжения работы. Подробная хронология завершённых
этапов намеренно удалена, чтобы не расходовать контекст при каждом запуске.

## Цель проекта

Локальное single-user приложение для самостоятельного изучения словацкого A1:
Next.js/React/TypeScript + FastAPI/SQLAlchemy/SQLite + Codex CLI или
OpenAI-compatible AI provider.

Не добавлять без отдельного запроса: auth, multi-user, PostgreSQL,
микросервисы и deployment.

## Текущее состояние

- Курс содержит 8 модулей и 83 урока.
- Владелец вручную принял Modules 1–6: 67 уроков. Сейчас он проверяет Module 7;
  конкретный завершённый диапазон внутри модуля ещё не указан. Module 8 ожидает
  ручной проверки.
- Во frontend находятся содержание курса и генерация практики; SQLite хранит
  состояние, настройки, историю AI и резервные копии.
- Этапы 0–9 плана укрепления завершены. Runtime data направлены в локальную
  папку приложения; реальная legacy-БД безопасно скопирована, прошла SQLite
  `quick_check`, а исходник сохранён без изменений.
- Персональный профиль ученика по умолчанию не отправляется AI provider;
  передача возможна только через явный `SHARE_PRIVATE_TUTOR_PROFILE=true`.
- Проверенный пакет функций и документов опубликован в `origin/main`
  2026-09-23 по прямому запросу владельца; локальные служебные gates исключены.

## Последние изменения в рабочем дереве

- Добавлены плавающий переводчик RU↔SK, уточняющий вопрос к AI и история
  переводов с сохранением в SQLite и включением в backup format v2.
- Расширен словарь: 2050 исходных строк, 2032 уникальные карточки,
  25 тематических разделов; карточки распределены по 83 урокам.
- Добавлены чтение, упражнения и домашние задания по пройденным урокам,
  общая статистика и режим продолжения обучения.
- Добавлены локальные exercise packs и единый online/offline режим упражнений;
  эталонные ответы скрыты до проверки.
- Добавлены настройки внешнего вида, персональные шпаргалки, панель backup и
  инструменты разработчика.
- Все Codex CLI subprocess запускаются в пустой временной директории вне
  проекта; добавлены cleanup/error tests и privacy opt-in для профиля.
- SQLite, AI settings, launcher state и логи перенаправлены из репозитория в
  platform-specific data root. Добавлена безопасная one-time copy legacy-файлов
  без удаления/перезаписи и явный rollback opt-in.
- Устранён конфликт Next.js cache: dev использует `.next-dev`, production build
  — `.next`; сборка при работающем приложении больше не удаляет runtime chunks.
- Ужесточена AI boundary: сырой ответ ограничен по размеру, provider JSON
  проходит строгие Pydantic-схемы с bounds, а API стабильно различает неверный
  ответ (`502`), недоступность (`503`) и timeout (`504`) без утечки исключений.
- Защищён `CourseState`: schema v1 читается совместимо и сохраняется как v2,
  вложенные значения строго валидируются, а revision не позволяет устаревшим
  autosave или backup restore перезаписать более новый прогресс.
- SQLite startup включает foreign keys, busy timeout и WAL, проверяет
  целостность и version history, делает pre-migration backup и применяет
  additive migrations одной откатываемой транзакцией только к runtime-копии.
- Course и tutor HTTP routes разделены по предметным областям без изменения
  URL/response contracts; tutor validation, parsing, prompts, exercise logic и
  Codex/OpenAI-compatible adapters вынесены в отдельные focused-модули.
- Python dependency tree закреплён хешированным lock-файлом для Python 3.12;
  `install.cmd` и CI используют lock и `npm ci`. Pytest обновлён до 9.1.1,
  SQLite test connections закрываются явно, неожиданные warnings стали errors.
- CI дополнен Python/npm security audit и changed-range `git diff --check`;
  локальные `pip-audit` и production `npm audit` не нашли уязвимостей.
- Начальный `/page` chunk уменьшен с 493700 до 389084 байт gzip (−21,2%):
  дополнительные слова, статистика, редкие режимы, настройки и переводчик
  загружаются по требованию. CI контролирует бюджет и отсутствие словаря в
  стартовом chunk.
- Добавлены быстрые unit-тесты для приоритета progress merge, scoring с
  penalty, сброса состояния переводчика и отображения API-ошибок.
- Все frontend-запросы получили общий timeout/cancellation layer: 30 секунд
  для локальных операций и 310 секунд для AI, без blind transport retry.
  Timeout, cancellation, network и invalid JSON различаются стабильными
  ошибками; autosave по-прежнему защищён revision/`409`.
- README и целевые API/architecture/database/AI/testing документы сверены с
  фактическими routes, storage, backup v1/v2 и сетевыми контрактами.
- Материалы Modules 5–6 вручную приняты владельцем; Module 7 остаётся текущей
  точкой проверки без изменения его синих per-topic markers.

- Course content остаётся во frontend; SQLite хранит состояние.
- Frontend обращается к backend только через `frontend/app/lib/api.ts`.
- AI output всегда считается недоверенным и валидируется.
- SQLite reads не должны выполнять запись.
- Не читать и не публиковать `.env`, credentials, `.ai/private/`,
  `backend/data/`.
- Не очищать `del/`, `_git-package/`, `.git` и не менять историю Git.
- Общий Tutor UI и deployment остаются отложенными до отдельного запроса.
